# Ziwago v21 — целевая архитектура живого SNN-организма

**Дата:** 2026-11-13. **Статус:** исправленная спецификация и первый этап реализации; не объявление готовой v21.

Alexandria — Clean Connectome, база знаний и источник конструктивных идей. Ziwago — исполняемая система, которую рефакторим по этому чертежу. ## 1. Целевой коннектом: владение, время, свидетельства

### 1.1 Сквозной поток

```text
Вход → кодек → FO/TRN/HO → MoE-колонки → реальные спайки/L5
                ↑             ↓                  ↓
          AST/GW/BG/химия ← нагрузка/ошибка        ↓
                                 токенное окно → ридаут/TDR
                                                 ↓
                 предложение → grounding/closure → эмиссия → settle
                                                 ↓
                       наблюдаемый исход → один reward → local traces

NREM: разрешённый replay → tagged consolidation → проверка удержания
REM: гипотеза из памяти/графа → независимый validator → принять/отклонить
```

Продолжение рассуждения, речь, воздержание и сон — разные действия. Недостаток свидетельств не заменяется генерацией шаблонного «знания».

### 1.2 Единственный владелец каждого состояния

| Состояние | Владелец | Читатели |
|---|---|---|
| `time_ms`, фаза, ATP/Ado, глобальная химия | `OrganismPhysiology` | интегратор, кора, BG, сон |
| Порядок тика, обратные связи, очередь replay | `IntegratedOrganism` | API и отчёты |
| Мембраны, кальций, рефрактерность, ламинарные выходы | колонка/нейрон | измерение нагрузки, окна свидетельств |
| Traces, веса и медленная метапластичность | конкретный синапс | сон, инспектор |
| Уверенность и meta-сигналы | MetaHead/калибратор | BG, routing, replay |
| Evidence accumulator и открытое действие | `ContextualActionGate` | языковой исполнитель |
| Значение и происхождение фактов | graph/grounding authority | decoder, validator |
| Эпизод и последовательность | гиппокамп | replay, NSM, апикальная подсказка |
| Логиты, candidate IDs, решение об эмиссии | readout/TDR | исполнитель, проверка |
| Снимки | сериализатор | экспорт не меняет исходное состояние |

Локальные химические поля не становятся вторым независимым владельцем глобальных концентраций; вклад передаётся явным источником/полем. Новый модуль сначала получает владельца и точку потребления, затем реализацию.

### 1.3 Контракт времени

- Канон исполнения — моделируемое `time_ms`, не wall-clock. Диск, GC и отладчик не старят память организма.
- Физический шаг коры v20 — 1 мс; токен включает `IntegrationConfig.ticks_per_token` шагов. Число API-вызовов не равно возрасту синапса.
- Для постоянного источника: `x_new=x_target+(x_old-x_target)exp(-dt/tau)`. Импульс события и непрерывный источник различаются; reward не повторяется в `advance`.
- Спящие колонки стареют по тому же времени. Аналитическое пробуждение проверяется против пошагового, включая traces и ресурсы.
- Биологические часы MCA/NSM и ускоренные инженерные часы требуют явного отношения `model_ms/biological_ms` в будущих профилях.
- Read-only evaluation восстанавливает веса, динамику, очереди, химическое время и RNG после исключения. `learn=False` не означает отсутствия динамических изменений.

### 1.4 Пространства и формы

| Представление | Контракт |
|---|---|
| `x` | конечный вектор `n_input`; кодек и таламус согласованы |
| Спайки | `[batch, neurons_per_column]`; реальная активность, не суррогат |
| L5 текущего MoE | спайки соответствующего среза, не мембранные напряжения |
| Корковые признаки языка | нормализованные spike/L5-пулы; ширина вычисляется из коры |
| Дендритный ридаут | координаты ветвей собственной матрицы, не SDR-биты |
| SDR | отдельный код с объявленной шириной и плотностью |
| VSA | размерность и binding принадлежат encoder |
| Кандидаты | стабильные token IDs и отображение в столбцы всех банков |

Размеры 8192/2048/64 разных механизмов не взаимозаменяемы. Проверяются форма, нормировка, нулевой вход и смысл проекции, а не только возможность умножить матрицы.

## 2. Физическое ядро и языковое окно

### 2.1 Сохраняем существующие механизмы, проверяем их действие

Многокомпартментные нейроны, апикальная ошибка, локальное обучение, FO/TRN/HO, sparse MoE и химия остаются основанием. Эквивалентность AdEx, Larkum/BAC, OU-шума и ламинарного каскада проверяется отдельно: название класса не доказывает биофизическую эквивалентность.

- Нагрузка выводится из измеренных токов/спайков и объявленной модели стоимости. ATP симуляции не называется измеренными джоулями GPU.
- `f_mod=0` действительно закрывает обучение при дефиците и во сне. NREM-консолидация — отдельное явно разрешённое действие.
- Signed DA участвует в локальном правиле один раз; tonic/phasic не складываются скрыто в каждом потребителе.
- Новый апикальный усилитель не добавляется поверх существующего без проверки двойного эффекта. Larkum оценивается по изменению напряжения/плато и последующего поведения.
- Возбуждение/торможение калибруется на устойчивом режиме. Молчащая кора не компенсируется константой на выходе.

### 2.2 Исправление потери свидетельств

Прежний `IntegratedOrganism.present` выполнял K физических тиков, но возвращал только последний. Спайки до последней миллисекунды могли исчезнуть из языкового входа.

Новый контракт: `S_window=(1/K)ΣS_t`, `L5_window=(1/K)ΣL5_t`. Сохраняются участвовавшие эксперты, средние веса их фактического выбора и сырые spike counts `[K,n_columns]`. Полностью молчащее окно остаётся нулевым. Агрегация не делает дополнительных физических шагов.

`SpikingLanguageLoop.predict` обновляет `last_features`. История содержит все физические тики, а не только токенные окончания; предел 512 строк — существующий бюджет `SpikingLanguageLoop.step`, не научная константа.

**Граница точности:** проектор учится на тех же признаках, что inference. Остальные поля `MoECortexOut` (ошибки, coherence, `active_neurons_this_tick`) описывают последний физический тик, не статистику окна. Апикальная коррекция использует средний routing credit и последнее локальное состояние колонки. Это не точный временной градиент окна и не BPTT. Дальнейший temporal credit должен использовать реальные eligibility, а не неограниченную ленту состояний.

**Приёмка:** окно равно ручным K тикам; полное состояние совпадает; ранний спайк сохраняется при тихом финале; нулевое окно не создаёт логиты; inference/learn согласованы; snapshot повторяет результат и растр.

## 3. Модули Alexandria v3: конкретные решения

### 3.1 TDR — candidate-first декодирование

Источник: [ARCH-TDR-001](file:///C:/Users/yarma/Desktop/AlexandriaProject/architecture/subsystems/ARCH-TDR-001.md). Основание: [readout](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cognition/language/readout.py), [predictive readout](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cognition/language/predictive_readout.py), [spiking language](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/spiking_language.py).

**Сейчас:** нулевые дендритные строки уже исключаются из умножения, но логиты строятся по всему зарегистрированному словарю. PC-rescoring после этого не устраняет upstream-затраты. Полный TDR отсутствует.

**Решение:**

1. Encoder-owned token codes → инвертированный SDR-индекс и индекс VSA. Новая случайная таблица, не связанная с encoder, не считается weight tying.
2. Pool A/B формируется до вычисления больших банков; все каналы используют один упорядоченный набор ID. Полный cosine scan B остаётся dense bottleneck и учитывается в цене.
3. Scorer собирает dendritic/core/SWR/bank/cortical/PC только по выбранным столбцам. При полном pool он воспроизводит нынешние логиты.
4. На обучении target включается в pool; частота принудительного включения логируется. При inference gold-target недоступен.
5. Измеряются candidate recall и потерянная масса относительно полного scorer. Усечённый softmax не выдаётся за вероятность полного словаря.
6. Виртуальный отказ не BPE-токен. Пустой pool, нулевой сигнал, бюджет и grounding имеют отдельные причины отказа, без случайного fallback.
7. `propose → validate → emit → settle`: отказ не подтверждает эмиссию, накопление ограничено временем, outcome учитывается один раз.

Bounded self-bias допустим после проверки NSM. **Униграммный prior P0 из Alexandria не переносится:** в Ziwago запрещена n-граммная генерация. Retrieval-частоты не становятся обходным языковым каналом.

**Приёмка:** candidate recall, held-out loss, replay/compose, precision/coverage отказов, полный latency/RAM и число обработанных столбцов. K=128 и порог 0.42 из карточки — гипотезы для калибровки, не обязательные production-константы. Уменьшение списка без стоимости поиска не считается ускорением.

### 3.2 MCA — локальная память синапса

Источник: [MATH-MCA-001](file:///C:/Users/yarma/Desktop/AlexandriaProject/math/plasticity_equations/MATH-MCA-001.md). Основание: [synapse](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/core/synapse.py), [column](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/column.py).

**Сейчас:** fast/slow weights, eligibility, tag и локальный BCM существуют. `theta_m` обновляется из сглаженного квадрата активности; это не пер-синаптический slow `m_ij` карточки.

**Решение:**

- Разделить `e` (контингентность), `tag` (консолидационный допуск), `m` (восприимчивость), `F` (важность) и `w_anchor` (защищаемая точка).
- Непрерывные источники нормировать по dt, спайковые импульсы добавлять один раз. Внешние часы уже есть — второй clock не вводить.
- Для `m∈[0,1]` использовать экспоненциальную релаксацию к bounded activity-target. Источник `(w-w0)^2` сам по себе границ не гарантирует.
- Порог должен иметь ненулевой масштаб влияния: `theta0×(1+beta*m)` при `theta0=0` не работает.
- Выбрать один закон многомасштабной консолидации. Benna–Fusi не включать поверх других slow-weight правил без проверки суммарного обновления и бюджета.

**Приёмка:** subdivision/rehydration, signed reward, конечные traces, реальное изменение порога, новое усвоение и старое удержание. Биологические tau переводятся в модельный профиль; снижение attenuation само по себе не цель.

### 3.3 FSP — важность и сон без глобального backward

Источник: MASTER_BLUEPRINT §III.7. Основание: [щит Fusi–Zenke](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/next16_core.py#L363), [EWC](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/learning/ewc.py).

**Сейчас:** живой щит накапливает magnitude `u_slow` и подавляет обновления. EWC-инфраструктура требует autograd/backward и не является готовой вставкой в detached SNN.

Для локального scorer `z_v=aΣ_r d_r w_rv+b_v`, `p=softmax(z)`:

- score-gradient наблюдения: `g_rv=a d_r(1[y=v]-p_v)`;
- empirical Fisher: среднее `g_rv²` по наблюдениям;
- conditional model Fisher: `F_rv=(a d_r)²p_v(1-p_v)` при ожидании по `y~p`.

Оценки не тождественны. Коэффициент `a` берётся из реального вклада банка в общие логиты. Eligibility не переименовывается в Fisher.

**Решение:**

1. Сначала magnitude-щит против ослабленного/отключённого при одинаковых данных, seed и бюджете; одновременно измерить forgetting.
2. F/anchor хранить в объявленном бюджете активных параметров. Дополнительные плотные матрицы могут уничтожить выгоду локальности.
3. Ограничить регуляризующую коррекцию. Возможный proximal-step: `w_new=(w+eta*u_task+eta*lambda*F*w_anchor)/(1+eta*lambda*F)` при неотрицательных F/lambda/eta; параметризация проверяется на локальной задаче.
4. NREM оценивает важность на разрешённом replay; anchors меняются после проверки удержания. Собственный ответ не становится gold-label.
5. Не заменять всю важность `F_infinity`; hard-mask — явная обратимая политика с резервом пластичности.

Limiter ридаута сохраняется: ограничение эффективного logit-step связано с кривизной softmax. Частое срабатывание не разрешает убрать защиту или произвольно увеличить шаг.

**Приёмка:** локальный Fisher сверяется с finite differences/reference-autograd в маленьком тесте; живой путь без backward. Проверяются loss, retention, step bounds, память и NREM round-trip.

### 3.4 ACL — глиальный контроль по тайлам

Источник: MASTER_BLUEPRINT §III.2. Основание: [AstrocyteMicrodomain](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/astrocyte.py).

**Сейчас:** микродомен не включён в интегрированный путь. Astro-NMDA recurrence — другой механизм. В микродомене два затухания; заявленная tau не равна эффективной.

**Решение:** на тайл хранить `C_i`, гейт, readiness/PNN и возраст. Drive нормируется на размер тайла и dt. Диффузия — нормированный лапласиан с проверкой среднего; шаг ограничивается устойчивостью либо используется устойчивый решатель.

Реакционная часть: `C_new=C_target+(C-C_target)exp(-dt/tau_C)`. Sigmoid/tanh выбирается по дозовой кривой, не по имени в карточке. Гейт действует в одной объявленной точке NMDA/release/пластичности, без повторного перемножения одного сигнала.

Интеграл активности — экспозиция, не выученность. PNN-закрытие требует DCC-readiness и retention; адресное переоткрытие и квота пластичных тайлов обязательны.

**Приёмка:** измеренная tau, независимость от размера тайла, diffusion conservation, bounds, `off/phantom/on`, wall-time/RAM, отсутствие общего замораживания. До замера не обещать <1% overhead.

### 3.5 DCC — развитие по готовности

Источник: [ARCH-DCC-001](file:///C:/Users/yarma/Desktop/AlexandriaProject/architecture/subsystems/ARCH-DCC-001.md).

**Сейчас:** контентный curriculum не равен зональному онтогенезу; полного контроллера зрелости нет.

**Решение:** возрастной prior `m_z=1-exp(-t/tau_z)` задаёт порядок возможностей, но закрытие определяется независимой readiness. `eta=4m(1-m)` выключает обучение при m=0 и m=1: стартовое состояние и резерв адаптации должны быть объявлены, а не исправлены скрытым floor.

Readiness-компоненты нормируются в `[0,1]`. E/I-score должен быть bounded, например `exp(-abs(log((E+eps)/(I+eps))))`, а не неограниченно отрицательный `1-|EI-1|`; `E=I=0` не считается зрелым равновесием. ITPC требует достаточных событий, качество — независимых заданий.

Закрытие требует устойчивого окна, гистерезиса, удержания и свободной пластичной ёмкости. Сдвиг распределения допускает адресное переоткрытие. Возраст, причина и затронутые тайлы сериализуются.

**Приёмка:** обучение с рождения, стадийность, запрет закрытия при тишине, резерв пластичности и адаптация без разрушения старого.

### 3.6 NSM — автобиография и настроение

Источник: [ARCH-NSM-001](file:///C:/Users/yarma/Desktop/AlexandriaProject/architecture/subsystems/ARCH-NSM-001.md#L79).

**Сейчас:** быстрая limbic-valence — opt-in, не persistent self-vector и не автобиография.

**Решение:** переиспользовать эпизоды гиппокампа через стабильный ID, время, результат и provenance; не дублировать полные истории. K=1024 в карточке — ёмкость эпизодов, не VSA-размерность.

`tanh(k_DA∫DA_phasic dt)` требует k_DA с обратными единицами интеграла. EW-среднее прошлых эпизодов не обязано возвращаться к нулю без новых событий: числитель и знаменатель затухают одинаково. Для нейтрального восстановления нужен отдельный baseline-relaxation.

Self-vector — нормированная сумма связанных эпизодических кодов в пространстве encoder; пустая память даёт ноль. Только bounded additive prior, не способ отменить grounding/отказ/факты. Настроение не повышает достоверность памяти.

**Приёмка:** round-trip, bounded storage, neutral empty state, signed impulse/recovery, отсутствие leakage, изменение приоритета без появления неподтверждённых фактов.

### 3.7 SCL — ресурсный профиль и checkpoint ownership

Источник: [ARCH-SCL-001](file:///C:/Users/yarma/Desktop/AlexandriaProject/architecture/topologies_and_wiring/ARCH-SCL-001.md). Основание: [MoE/сериализатор](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/moe_cortex.py).

**Сейчас:** neurons count не определяет память. Значимы readout, traces, shields, snapshots и restore copies. Профили Alexandria с другими dtype/железом не дают гарантий для этой машины.

**Решение:** именованные профили после инвентаризации уникальных storages. Профиль включает columns/neurons/top-k, dendrites/vocabulary, banks/traces/replay, snapshot strategy, dtype, CPU/VRAM и запас приложениям пользователя.

`M_peak=M_live+M_inflight_payload+M_conversion+M_snapshot+M_allocator`. `numel×element_size` суммировать по уникальным хранилищам, не дважды по алиасам. Read-only/writable ownership явный.

Checkpoint v21: manifest, проверяемые shards, поэтапное чтение, однократное writable-размещение. Формы/dtype/checksum/совместимость проверяются до принятия состояния, публикация атомарна. Inference-load и train-resume различаются контрактом; пропущенную пластичность нельзя молча обнулить.

**Проверенный и отклонённый вариант:** cache префиксов `export_runtime_paths` сократил обходы, но замедлил экспорт маленькой коры. Первый вариант: 1.126 → 1.270 мс (+12.8%); упрощённый: 1.148 → 1.199 мс (+4.5%). Исходный экспорт восстановлен; контрактные тесты сохранены. Источники: [замер 1](file:///D:/Ziwago18-storage/Produce/v21_snapshot_benchmark_20261113.log), [замер 2](file:///D:/Ziwago18-storage/Produce/v21_snapshot_benchmark_v2_20261113.log), по 8 чередующихся серий × 30 экспортов, 2 колонки × 32 нейрона, 342 пути. Это не замер генерации или production-модели и не решение checkpoint OOM.

Hot/cold и CSR — после эквивалентности пробуждения. Не удалять строки, не активные в одном прогоне. SparseProp/Blocked-ELL оцениваются по реально исполняемому kernel и доступной GPU, не по теоретическим MACs.

**Приёмка:** точный round-trip/RNG/aliasing, пик commit/RSS/VRAM, latency токена, отказ до опасного allocation и сохранение обучения после resume.

### 3.8 TCC — реляционные аттракторы

Источник: MASTER_BLUEPRINT §III.4. Основание: [hippocampus](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/memory/hippocampus.py), [dual hippocampus](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/memory/dual_hippocampus.py).

**Сейчас:** Laplace time cells, 1-D grid-подобный код и CA3-полюса не равны CANN на `T²`. Dual hippocampus подключён как opt-in OFF; весь стек нельзя называть мёртвым.

**Решение:** bounded эксперимент реляционного переноса, не физическая арена. Проверять wrap, bump stability, интерференцию и обратимое декодирование. Фазовая сумма коммутативна и не представляет произвольный направленный/некоммутативный граф без дополнительных типов/операторов. Gridness не доказывает текстовую причинность.

**Приёмка:** held-out relations, альтернативные пути, циклы/aliasing; сравнение с VSA/graph по качеству и цене. Масштабировать после преимущества.

### 3.9 ADMC — энергия, внимание и прогресс

Источник: MASTER_BLUEPRINT §III.8. Основание: OrganismPhysiology и виртуальная интероцепция.

**Сейчас:** ATP/Ado, sleep pressure, zero gate и энергетические актуаторы существуют; полной learning-progress цели нет.

**Ближайшее изменение:** глобальное давление сна S подавляет target ACh:

`ACh_target=(ACh_baseline+attention_gain×min(attention,1))/(1+(S_mid/theta_Ado)^2)`;
`ACh_new=ACh_target+(ACh_old-ACh_target)exp(-dt/tau_ACh)`.

S_mid — среднее давления начала/конца подшага. Это bounded target и релаксация, не повторное умножение текущей концентрации. `ach_ado_half_saturation` положителен, валидируется и экспортируется; значение 0.6 — инженерная гипотеза конфигурации, не измеренная физиологическая константа.

**Ограничение:** это не полная фазовая модель ACh; REM-холинергическое возбуждение отдельно не реализовано. Формулу усталости нельзя выдавать за физиологически точную модель всего сна.

**Далее:** `J=progress-λ_E×cost`, где progress — улучшение на сопоставимых отложенных/повторных заданиях, не сырая surprise. Иначе агент предпочитает шум. Cost берётся из модели нагрузки; λ_E согласует шкалы. Политика задач и пределы exploration логируются.

**Приёмка:** постоянный target даёт точную экспоненту, переменный — сходимость по dt; давление подавляет, восстановление снимает подавление; reward/ATP/остальные оси не ломаются. Для J отдельно noisy-TV control и измеренный learning progress.

### 3.10 CSGL — композиция и причинная дисциплина

Основание: [genesis engine](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/genesis_engine.py), [verified/grounding/sleep](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/organism/verified.py).

**Сейчас:** relational graph/declared interventions полезны, но не идентифицированная observational SCM. Genesis role/closure/valence-компоненты существуют; полная генеративная проводка остаётся незавершённой.

**Решение:**

- Роли извлекаются из evidence с provenance и открытым словарём; hardcoded примеры не универсальная онтология.
- Content-план (сущности/роли/отношения) отделяется от form-реализации. Replay эпизода не выдаётся за композиционное обобщение.
- Closure проверяет сохранение утверждений/ролей. Обратная реконструкция тем же ошибочным каналом не гарантирует истину; нужен source-grounding.
- Рёбра различают `observed_association / declared_rule / intervention_supported`. STDP не повышает автоматически epistemic статус.
- Контрфактуал требует declared model/предпосылок либо идентификации. «В данной модели» отделяется от внешнего факта.
- REM-гипотеза не попадает в знание без независимого acceptance-validator; `validator=None` остаётся отказом.

**Приёмка:** novel roles, held-out family composition, contradiction/missing evidence → отказ, intervention-vs-association controls и отсутствие train/test leakage. Replay оценивается отдельно от compose.

### 3.11 Workspace / Meta / AST / PCI

Основание: [workspace](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/consciousness/workspace.py), [MetaHead](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/consciousness/meta_head.py), [AST](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/consciousness/attention_schema.py).

**Сейчас:** confidence → action uncertainty, AST → TRN/routing, GW → broadcast уже соединены в интегрированном тике. Другие outputs не считаются подключёнными по наличию полей.

**Решение:** один bounded mapping на исполнитель: BG threshold, TRN gain, GW sensitivity, replay priority. Контролировать прежнюю связь при проверке новой, чтобы различить пользу и дублирование. Производные гейты имеют единый источник, а не расходящиеся копии.

Uncertainty калибруется отдельно от surprise/error. Она может продлить накопление, но не отменяет deadline, сон и независимую проверку эмиссии.

PCI-подобный прибор получает baseline/perturbed растры из одного snapshot/RNG. Нужны binarization threshold, window, entropy convention и blank/random controls. При H(p)=0 результат «не определён». Сжатие bytes зависит от заголовка/длины компрессора; нужны поправка и контроль. Порог 0.52 из Alexandria не является нормой диагностики сознания SNN.

**Приёмка:** гейт меняет свой исполнитель в парном опыте без двойного feedback; PCI доступен при валидном эксперименте и явно недоступен иначе. Само число не доказывает субъектность.

## 4. Сон как транзакция обучения

1. **Вход:** физиология определяет фазу; команда запрашивает сон, не подменяя измеренное восстановление.
2. **NREM:** tagged episodes, ограниченная очередь, локальная консолидация, селективный homeostasis. FSP/PNN — после собственных тестов.
3. **REM:** кандидаты отношений/аналогий из памяти. Число графов/узлов/пар ограничено; экспоненциальное выравнивание без бюджета запрещено.
4. **Acceptance:** независимая проверка качества и удержания. Declined/no-validator не меняет авторитетное знание.
5. **Выход:** химическое восстановление по модельному времени; сохраняются counters, причины отказа, изменённые банки и fingerprint.

Существующий сон v19/v20 различается. Новая политика получает одного владельца; legacy sleep и новый консолидатор не обновляют один эпизод дважды. Выполнение сна и улучшение качества — отдельные метрики.

### Шестой этап в коде: контроллер зрелости DCC (этап E, часть 2)

- Новый [DevelopmentalReadinessController](file:///C:/Users/yarma/Desktop/Ziwago18/ziwago/cortex/dcc.py): программный контур созревания зон, дающий ACL внешний сигнал readiness. Возрастной prior `m_z=1−exp(−age/tau_z)` (детерминированно в `tick`); окно гиперпластичности `eta=eta_max·4m(1−m)` — **ноль на краях** `m=0` и `m=1`, без скрытого floor; рампа торможения `g_inh=g_inh_max·m^beta`; отжиг шума `sigma=sigma_0·exp(−k_sigma·m)`.

Квота `min_plastic_fraction` запрещает глобальное замораживание (закрываются top-readiness в пределах резерва). Адресное переоткрытие `reopen` сохраняет возраст/зрелость и пишет причину. `effective_plasticity()=eta·(~closed)`. Сериализация `export/load_state_dict` с проверкой форм.

Single-bump WTA аттрактор не представляет множественные отношения одновременно; коммутативная фазовая сумма не представляет направленный граф без типизированного оператора. Преимущества над простым VSA-baseline по качеству и цене **нет** → не масштабировать. Без global backprop (фиксированная случайная проекция + сохранённые якоря), без n-грамм. Загрузчик и чекпоинты не изменялись по указанию пользователя.

## 8. Неприкосновенные ограничения

- Без surrogate/global backprop в живом языке; reference-autograd — только независимый маленький математический тест.
- Без n-граммной генерации, фиктивных спайков, gold leakage, отмены sleep-validator и обхода grounding.
- Три защиты family/prompt/document leakage сохраняются.
- Оригинал и архивный мастер только для чтения. Перед правками создан [архив исходников](file:///D:/Ziwago18-storage/Archive/refactoring_v21_before_20261113.zip); он не заменяет backup обученных весов.
- Тяжёлые процессы через `tools/limited_run.py`; тесты и обучение не конкурируют. Артефакты на D:. Свободная память проверяется перед запуском; гарантии не выводятся из имени Tiny.
- Числа сопровождаются config-полем, формулой или отчётом. Гипотеза, контракт, наблюдение и production-результат подписываются отдельно.
- Пропущенные/заблокированные тесты и отрицательные результаты показываются прямо. Golden не меняется ради прохождения.
